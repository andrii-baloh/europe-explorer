## Техническая реализация

- Видео выбираются из lessonVideosUnique.json по ID урока и языку.
- Ссылка в «Материалах» совпадает по языку и ролику с основным видеоблоком.
- При смене языка старый iframe размонтируется. Встраивание происходит только после нажатия; для Studyflix/WDR/Planet Schule и иных источников без разрешённого iframe предлагается ссылка на сайт автора.
- Для пяти дополнительных сюжетных игровых глав остаются отдельные материалы RU/DE.
