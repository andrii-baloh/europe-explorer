# Europe Explorer — учебная редакция 2.0

Обновление основано на исходном проекте `europe-explorer.zip` и редакционном пакете `europe_explorer_content_ru_de.json`.

## Что изменилось

- Стартовая страница с сюжетной интригой и связью пяти глав.
- Перед **каждой** интерактивной сценой — объяснения и цель исследования.
- После сцены — три пошаговых задания, подсказки и **самостоятельная** проверка объяснения (никакой ложной автоматической оценки).
- В конце каждой главы — вопрос для самопроверки, словарь, вывод и связь со следующей главой.
- RU/DE — настоящий переключатель языка для основных текстов и элементов всех пяти интерактивных сцен.
- Сюжет и задания приведены в соответствие с **реальными** механиками: ферма выращивает травы, пшеницу и цитрусовые; Альпы показывают высоту и складчатость; транспорт моделирует перевозку из Роттердама и водную нагрузку курорта.
- В дневнике появились итоговый вопрос, пояснение смысла JSON/TXT и понятная структура открытий.

## Что специально не менялось

`src/model.mjs`, `public/data/europe.geojson`, математические формулы климатограммы, высотная модель, интерактивные состояния фермы и транспорта, схема записей дневника версии 1, ключ localStorage `europe-explorer-v1`, импорт/экспорт JSON/TXT, алгоритм объединения записей, React/OpenLayers/Recharts/Vite/Tailwind стек.

## Запуск и сборка

Node.js 22.12+; в папке проекта:

```bash
npm ci
npm test
npm run build
npm run dev
```

Сборка создаёт актуальную папку `dist`. **Не публикуйте старую папку `dist` из исходного архива.**

## Публикация

Сайт `https://europe-explorer-baloh.tatanabalog01.chatgpt.site/` опубликован с помощью ChatGPT Sites. Этот ZIP — модифицированный исходный проект и **не обновляет текущую публикацию автоматически**. Чтобы опубликовать на том же адресе, нужно открыть связанную с ним сессию редактирования в разделе «Сайты» и использовать обновлённый проект, проверить предпросмотр и отдельно нажать «Опубликовать».

## Тестирование

`npm test` включает проверки географических моделей, сохранения, карты и полноты учебных материалов. После установки зависимостей проверить `npm run build`, интерактивные сцены, оба языка и сохранение/импорт JSON.
