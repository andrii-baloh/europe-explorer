# Видео для Europe Explorer · языковые версии

## Как выбирается язык

Переключатель **RU / DE** определяет язык настоящего видео, а не только интерфейса. В главном курсе **35 из 60** уроков снабжены тематическими видео (12 тем + близкие тематические повторы), а для остальных 25 видео не заявлено. Для всех 35 доступен русский и немецкий источник. Дополнительно пять первоначальных игровых глав имеют языковые видеоверсии.

- **RU**: русскоязычные уроки на YouTube, один видеоматериал на RUTUBE и один внешний видеорепортаж Euronews на русском языке.
- **DE**: исходная подборка на немецком YouTube в большом курсе и тематические фильмы Planet Schule в пяти первоначальных игровых главах.
- При переключении языка компонент видеоплеера **пересоздаётся**, старый iframe удаляется. Ролики не запускаются без нажатия пользователем.
- Если YouTube/RUTUBE запрещает встраивание в конкретной стране или на устройстве, в карточке есть прямая ссылка на оригинал.
- Внешние ресурсы остаются на сайтах правообладателей. Файлы с видеозаписями не копируются в репозиторий.
- Не каждый пример в русскоязычном видео относится к Европе; например, видео о сельском хозяйстве или экономике может использовать примеры из России. Такие материалы иллюстрируют **общую концепцию**, не подменяя содержание урока о Германии или Европе.

Немецкие материалы пяти глав сохраняют ссылки на **Planet Schule**. Немецкая подборка большого курса описана непосредственно в `src/courseVideos.ts`.

## Проверки

`npm test` проверяет отдельные источники для обоих языков и отсутствие подмены русских видео немецкими. Браузерный сценарий `.git/smoke-bilingual.cjs` прогоняет 60 уроков, 35 видеокарточек RU и DE, 5 отдельных глав, переключение RU → DE → RU, остановку iframe и мобильную вёрстку.
